# Student Management System — UML Diagrams

This folder contains PlantUML source diagrams for the Student Management System.

## Files
- `use-case.puml` — actors and use cases
- `class-diagram.puml` — main classes and relationships
- `login-sequence.puml` — login flow
- `component-diagram.puml` — system components and dependencies

## Preview / export
Open a `.puml` file in a PlantUML-compatible editor or use the PlantUML extension to preview/export it. These are source diagrams; the StarUML native `.mdj` project is provided separately in the chat download.
